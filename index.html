What is this space?

These demos are interactive prototypes designed to look and feel like real SharePoint pages and learning modules — built for stakeholder review and sign-off before any production development begins. Each demo is fully interactive: click through views, check off tasks, and simulate system behavior.

Once a design is approved, each component maps to a SharePoint + Power Platform production build (SPFx web parts, Power Apps, Power Automate) or an LMS-ready course package. Nothing here requires a SharePoint license or LMS account to view.

How to use these demos
01
Explore all views
The SharePoint demos have a purple prototype banner — use it to switch between role views. In production, SharePoint permissions handle this automatically so each person only sees their own.
02
Interact with the content
Checklists are clickable and update progress in real time. The course module has scenarios, a knowledge check, and a nav bar you can use to jump between sections.
03
Collect and share feedback
Share this link with stakeholders for review. Once a design is signed off, each component maps to a real SharePoint, Power Platform, or LMS build step.
